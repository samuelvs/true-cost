
# 🧾 TrueCost [TrueCost](./public/logo.svg)

**See the real price behind the tag.**  

TrueCost is a modern React app that helps you calculate the real cost of products in the U.S. — including local tax rates and live currency conversion. Built with Vite and React Hooks.

![Badge](https://img.shields.io/badge/Vite-React-blue?logo=react)
![Badge](https://img.shields.io/badge/API-Unirate-blueviolet)
![Badge](https://img.shields.io/badge/deploy-Vercel-black?logo=vercel)

## ✨ Features

- ✅ Auto tax calculation for major U.S. cities
- 💱 Live currency conversion (USD → BRL, EUR, GBP)
- ⚛️ Reactive UI using React + Hooks
- 🚀 Ready to deploy with Vercel

## 🚀 Getting Started (Local)

1. Clone the repository:

```bash
git clone https://github.com/your-username/true-cost.git
cd true-cost
```


2. Install dependencies:

```bash
npm install
```


3. Add your API key to a .env file:


```bash
VITE_UNIRATE_API_KEY=your_api_key_here
```
You can get a free API key from unirateapi.com



4. Run the development server:


```bash
npm run dev
```
Visit http://localhost:5173 in your browser.


## 📦 Building for Production

```bash
npm run build
```
Output goes to /dist.
